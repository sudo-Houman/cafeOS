# ☕️ CAFE OS چیست؟

**Cafe OS** یک سیستم مدیریت حرفه‌ای و هوشمند برای کافه‌هاست که عملیات روزانه را در یک سیستم یکپارچه مدیریت می‌کند.

🧾 سفارش‌ها • 📦 موجودی • 💳 پرداخت • 👨‍🍳 کارکنان • 💰 هزینه و سود • 📊 گزارش‌ها • 🔔 اعلان‌ها • 🤖 اتوماسیون

> 🖤 **به‌جای چند ابزار مختلف، همه‌چیز در یک سیستم.**

# 🧠 SMART INVENTORY

Cafe OS فقط موجودی را نمایش نمی‌دهد؛ **مصرف واقعی مواد اولیه را محاسبه می‌کند.**

مثال:

☕ Espresso = `20g Coffee`

100 سفارش:

`100 × 20g = 2000g`

یعنی:

📦 کسر خودکار موجودی  
📊 ثبت مصرف  
🚨 بررسی حداقل موجودی  
🔔 هشدار در صورت نیاز  
🛒 پیشنهاد خرید

# 🚀 QUICK START

    git clone <repository-url>
    cd cafe-system
    python -m venv venv

Windows:

    venv\Scripts\activate

Linux / macOS:

    source venv/bin/activate

Install:

    pip install -r requirements.txt

Run:

    uvicorn app.main:app --reload

API Docs:

    /docs
